# السيرة الذاتية — قصي عبد الحفيظ حسن احمد

**الرابط المباشر:** https://qusihassan.github.io/cv/

سيرة ذاتية احترافية ثنائية اللغة (عربي / English) بتصميم متحرك ومتجاوب مع الجوال والويب.

## المحتويات

| الملف | الوصف |
|---|---|
| `professional_cv_qusi.html` | صفحة السيرة الذاتية الكاملة (التصميم، الترجمة، الحركات) |
| `index.html` | يحوّل الرابط القصير مباشرة إلى صفحة السيرة الذاتية |
| `photo.jpg` | الصورة الشخصية |

## المميزات

- تبديل اللغة بين العربية والإنجليزية بحركة تقليب الصفحة، مع حفظ اللغة المختارة في المتصفح.
- مسميات وظيفية تُكتب حرفاً حرفاً، أشرطة إتقان متحركة، وأقسام تظهر عند التمرير.
- بطاقات للتقنيات: C++ · JavaScript · TypeScript · React · Go · HTML/DOM · Odoo · Microsoft Dynamics 365 · Claude Code · Claude Design.
- زر طباعة / حفظ PDF بتنسيق خاص للطباعة.
- تصميم متجاوب للحاسوب والتابلت والجوال.

## النشر

الموقع منشور عبر **GitHub Pages** من فرع `main` (المجلد الجذر). أي تعديل يُدفع إلى `main` يظهر على الرابط خلال دقيقة تقريباً.

## التشغيل محلياً

```bash
py -m http.server 8000
```

ثم افتح: http://localhost:8000/
